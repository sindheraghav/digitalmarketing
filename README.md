# Real Growth Tech

Premium Digital Solutions landing page.
Real Growth Tech is a digital marketing agency providing services such as
Website Designing, Development, SEO, and Lead Generation.

## Features

- **Responsive Design**: Built with Tailwind CSS, ensuring the site looks
  great on all devices, from mobile phones to desktops.
- **Glassmorphism UI**: Uses modern glassmorphism effects for cards and
  components, providing a sleek and premium look.
- **Smooth Animations**: Includes custom keyframe animations like floating
  elements and slow pulses for an engaging user experience.
- **Video Background**: Features a captivating video background in the hero
  section to immediately grab visitors' attention.
- **Floating WhatsApp Button**: Allows easy and quick communication for
  visitors.
- **Interactive Mobile Menu**: A smooth, sliding mobile menu for better
  navigation on smaller screens.

## Technologies Used

- **HTML5**
- **Tailwind CSS**: via CDN for rapid and modern styling.
- **Google Fonts**: 'Outfit' and 'Plus Jakarta Sans' for typography.
- **FontAwesome**: For vector icons.

## How to View

1. Clone or download the repository to your local machine.
2. The main file is an HTML file (e.g., `WebGenie-saved(4) (1).html`).
3. You can simply double-click the HTML file to open it in your default web
   browser. No server setup or build process is required!
